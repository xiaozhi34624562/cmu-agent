What each team does:

- **Platform** builds the GridLens backend: ingestion, storage, and the public API. Arjun Mehta, Staff Engineer, owns the Ingestion API. Katya Petrova, Senior Engineer, leads the storage work.
- **Forecasting and Data Science** builds the forecasting models and the analytics behind the Loss Analytics and Outage Detection modules. Jonas Weber, Senior Data Scientist, is the technical lead for Project Kestrel.
- **Apps** builds the GridLens web application and FieldKit, the technician companion application for phones and tablets that installers use on site.
- **Firmware** builds EmberOS, the firmware for the Meridian M4 and the Pulse S2. Sam Okonkwo, Senior Firmware Engineer, leads over-the-air updates. Mei-Ling Chou, Firmware Engineer, leads firmware for Project Heron.
- **Hardware Engineering** designs and tests the devices and runs the Boulder lab.
- **Site Reliability Engineering** runs the cloud infrastructure and the incident process. Hiro Matsuda is the on-call coordinator.
- **Security** protects company and customer data and runs the security program.
